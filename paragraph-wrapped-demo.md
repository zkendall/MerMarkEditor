## Paragraph rendering

The preview renders a native viewport in fullscreen, so the amount of text on the page depends on
the editor width and the selected font. A base viewport setting does not cap the rendering
resolution when window stretching is disabled. Longer explanations often wrap across several lines,
and clear paragraph spacing helps readers find the beginning of each new idea without changing the
spacing between the lines inside it.

Desktop scaling can increase the reported backing image beyond the physical resolution of the
monitor. That distinction matters when comparing measurements from different windows or displays. A
maximized window can incur the same resolution-dependent cost without entering true fullscreen.
Keeping these observations in a separate paragraph makes the explanation easier to scan and prevents
the next topic from blending into the previous one.
