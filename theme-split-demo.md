# Editor settings stay in control

A document should keep its font, line height, padding, and colors when the application changes appearance. These values belong to the Editor settings, so switching between Default and Minimal keeps this page consistent.

## The same document in both styles

Appearance changes the toolbar, sidebar, and other application controls. This sample uses the system font, a line height of 1.6, and identical padding in both screenshots.

> A quote keeps its document styling as well.

- Keep the selected font and line height
- Preserve the document width and padding

## Light code theme

Code blocks follow the Code theme setting, including when Minimal is selected. Light uses a subtle gray background and a palette that stays readable on it.

```javascript
// The Light code palette follows the Code setting.
const greeting = "Hello, World!";
function sum(a, b) { return a + b; }
```
